> Kingsley's **free 6-lesson Claude Code course** → Skool community funnel. Teaches anyone to build their first AI system in under an hour. Install via `curl` (no Git needed).

| Field | Value |

## The 6 lessons (`skills/lesson-*.md`)

| Lesson | What they build |
|--------|-----------------|
| 1 | **AI Brain** (CLAUDE.md) — a personal brief so every Claude session knows them |
| 2 | A custom **skill** — one command that does a repeatable task forever |
| 3 | **MCP** — how Claude connects to real tools |
| 4 | **Parallel agents** — multiple Claudes at once |
| 5 | A **real build** — a working web page for their actual work |
| 6 | The **full system** — everything wired together |

Each lesson is a slash command (`/kingsleyai:lesson-N`).

## Rules for Claude in this folder

- **Beginner-first** — zero jargon. Assume the reader has never opened a terminal.
- **Outcome-led copy** — "build X in 30 seconds", never "learn about Y".
- **curl, not git clone** — participants install without Git. Never instruct them to clone.
- **Workshop platform** — claude.ai browser OR Claude Code desktop app (both avoid the Git requirement).
- **Funnel goal** — every asset nudges toward the Skool community, not a hard sell.
- **Voice** — Kingsley's: direct, punchy, proof-heavy, Malaysian energy. No fluff.
